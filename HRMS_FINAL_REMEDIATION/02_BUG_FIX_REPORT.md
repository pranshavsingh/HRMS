# 02. Bug Fix Report

| Bug ID | Severity | Module / Location | Root Cause | Fix Applied | Verification Evidence | Status |
|---|---|---|---|---|---|---|
| `BUG-PROD-001` | **Critical** | Audit Service (`node_backend/src/services/audit.service.js:106`) | `actor?.tenant_id` was referenced instead of `user?.tenant_id`, throwing `ReferenceError: actor is not defined` during audit log broadcasts and aborting transactions. | Updated to `user?.tenant_id` with optional tenant propagation. | `prod_readiness_fixes.test.js`, `attendance_concurrency.test.js`, and live leave approval PASS. | **FIXED & VERIFIED** |
| `BUG-PROD-002` | **High** | DB Pool (`node_backend/src/db/index.js:42`) | Host MySQL server defaulted to `SYSTEM` (`+05:30`), while `mysql2` used UTC (`Z`), causing a 5.5 hour discrepancy in `NOW()` comparisons (breaking OTP expiration and worker lease expiry). | Added connection hook: `pool.on("connection", (c) => c.query("SET time_zone = '+00:00'"))`. | `otp.test.js` (7/7 PASS), `failure_injection.test.js` (25/25 PASS). | **FIXED & VERIFIED** |
| `BUG-PROD-003` | **High** | Site Service (`node_backend/src/services/site.service.js:237,290`) | Queries on `workforce_site_access` queried `AND can_view = 1`, which does not exist in schema (`ER_BAD_FIELD_ERROR`), crashing manager approvals. | Removed `AND can_view = 1` and aligned with schema. | `prod_readiness_fixes.test.js`, `attendance_concurrency.test.js` (5/5 PASS). | **FIXED & VERIFIED** |
| `BUG-PROD-004` | **Medium** | Web UI (`hrms_saas` Layout & Pages) | Desktop sidebar fixed width (`w-64`) and fixed container constraints caused page-level horizontal overflow on viewport widths <= 768px. | Made sidebar collapsible with mobile drawer and responsive toggler in `Layout.jsx` and `Navbar.jsx`; adjusted grid wrappers in `AdminDashboard.jsx`, `EmployeeDocuments.jsx`, and `Roster.jsx`. | Edge CDP automated responsive suite across 9 viewports (1920, 1440, 1280, 1024, 768, 430, 390, 375, 360): 180/180 PASS (0px page overflow). | **FIXED & VERIFIED** |
